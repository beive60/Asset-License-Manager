# Asset License Manager

動画編集者向けの素材ライセンス（URL、クレジット表記）管理および、YouTube概要欄向けクレジットテキスト自動生成ツールです。

ローカルの素材フォルダを走査し、JSON形式でクレジット情報を管理します。外部とのAPI通信を行わないません。

## 主な機能

* **ローカルファイル走査**: 指定した素材ルートフォルダ内の音声、画像、動画ファイルを自動検知します。
* **状態の動的監視**: 実ファイルの追加・削除を検知し、「新規未登録（Missing）」「登録済み（Filled）」「ファイル消失（File not found）」を自動判定します。
* **インテリジェント・ペースト (Excelライク操作)**:
  * 複数セルを選択してのコピー（TSV形式）に対応。
  * スプレッドシート等からコピーした複数列（URLとAttribution）の一括貼り付け。
  * **リピート適用**: 1行分のデータをコピーし、複数行を選択してペーストすることで、一括で同じクレジット情報を流し込めます。
* **概要欄テキスト自動生成**:
  * 選択した素材からクレジット情報を重複排除して抽出。
  * `\n`（文字としてのバックスラッシュ+n）を実際の改行に変換。
  * ニコニ・コモンズの親作品登録用ID（`nc12345`など）を自動抽出し、スペース区切りでリスト化。
  * 未記入の素材を「要確認リスト」として自動分離。

## 必須ディレクトリ構造

本ツールを正しく動作させるために、素材ルートフォルダの直下には以下のディレクトリ構造が必要です（アプリ起動時に存在しない場合は自動生成されます）。

```text
素材ルートフォルダ/
  ├─ audio/
  │   ├─ bgm/
  │   └─ se/
  ├─ picture/
  │   ├─ background/
  │   ├─ character/
  │   └─ item/
  └─ video/
      ├─ background/
      ├─ effect/
      └─ transition/
```

※ 上記の各フォルダ内に対応する拡張子のファイル（`.mp3`, `.png`, `.mp4`など）を配置してください。

## 使い方

1. **起動とフォルダ選択**:
   アプリを起動し、「素材フォルダ選択」ボタンから上記の構成を持った素材ルートフォルダを選択します。
   （※選択したフォルダパスは記憶され、次回起動時に自動で復元されます）
2. **クレジットの入力**:
   * 赤色で表示されている行（Missing）の `URL` 列および `Attribution` 列をダブルクリックして、配布元URLやクレジット表記を入力します。
   * Googleスプレッドシート等で管理している表からコピーし、セルを選択して `Ctrl+V` で一括入力が可能です。
3. **保存**:
   「保存」ボタンを押すと、素材ルートフォルダ直下にジャンル別のJSONファイル（`audio-assets-license.json` 等）が保存されます。
4. **テキスト生成**:
   出力したい素材の左端にあるチェックボックスをONにし、「テキスト生成」ボタンを押すと、概要欄にそのまま貼り付けられる形式のテキストファイルが生成されます。

## 開発・ビルド環境

* Windows 11
* Python 3.11+
* PySide6

ソースコードから実行・ビルドする場合:

```powershell
# 依存関係のインストール (uv推奨)
uv sync

# 開発実行
uv run python src/asset_license_manager/main.py

# EXEビルド (PyInstaller)
.\build.ps1
```
